## About the dataset

The data come from:

> Himes BE, Jiang X, Wagner P, Hu R, Wang Q, Klanderman B, Whitaker RM, Duan Q, Lasky-Su J, Nikolos C, Jester W, Johnson M, Panettieri RA Jr, Tantisira KG, Weiss ST, Lu Q. (2014). *RNA-Seq transcriptome profiling identifies CRISPLD2 as a glucocorticoid responsive gene that modulates cytokine function in airway smooth muscle cells.* PLoS One 9(6): e99625. https://doi.org/10.1371/journal.pone.0099625 (GEO accession: GSE52778)

**Biological question.** Asthma is a chronic inflammatory disease of the airways. Glucocorticoids (steroids such as **dexamethasone**) are one of the most common asthma treatments, but how they change gene expression in the cells that line our airways was not fully understood. The authors treated **human airway smooth muscle (ASM) cells** with dexamethasone and used RNA-Seq to find which genes turn on or off in response.

**Experimental design.**

+ Primary ASM cells from **4 human donors** (cell lines `N61311`, `N052611`, `N080611`, `N061011`).
+ Each donor's cells were either left **untreated (`untrt`)** or treated with **1 µM dexamethasone (`trt`)** for 18 hours.
+ This gives **8 samples** total (4 donors × 2 conditions). Because each donor has a treated and untreated sample, this is a **paired design**.

You can see this in the sample sheet:

```r
sampleinfo <- read.table("airway_sampleinfo.txt", header = TRUE, sep = "\t")
sampleinfo[, c("SampleName", "cell", "dex", "Run")]
```

**Where did our results file come from?** In a previous session we took the raw counts (`airway_rawcount.csv`), filtered out lowly expressed genes, normalized (`filtlowabund_scaledcounts_airways.txt`), and tested for differential expression between dexamethasone-treated and untreated cells using `edgeR`. The output of that test is `diffexp_results_edger_airways.txt`, and it is the only file we need today.

The columns we care about are:

| Column | Meaning |
|--------|---------|
| `feature` | Ensembl gene ID (e.g. `ENSG00000000003`) |
| `transcript` | Gene symbol (e.g. `TSPAN6`) – this is what we will use to label genes |
| `logFC` | log2 fold change, **dexamethasone vs untreated**. Positive = higher in treated cells (up-regulated); negative = lower in treated cells (down-regulated) |
| `logCPM` | Average expression level (log2 counts per million) |
| `F` | Test statistic from edgeR's quasi-likelihood F-test |
| `PValue` | Raw (nominal) p-value for each gene |
| `FDR` | **Adjusted p-value** (Benjamini–Hochberg false discovery rate) |

The other columns (`albut`, `ref_genome`, `.abundant`) are bookkeeping from the earlier analysis and we will not use them.

# Introduction

The volcano plot is a scatterplot that visualizes both the (log2) fold change and level of significance (usually −log10[p−value]). This data visualization enables the display of a large amount of data in a concise way. Typically, only a handful of datapoints in the volcano plot are of interest, also known as hits. The hits are datapoints that surpass a threshold that is defined by the user for both the significance and fold change. Annotation of hits (with names) is used to draw attention to these most relevant or interesting datapoints.

**Why −log10?** Small p-values mean strong evidence. Taking −log10 flips them so the *most significant genes end up at the top* of the plot (p = 0.01 → 2, p = 0.0001 → 4). Together with fold change on the x-axis, the plot takes the shape of an erupting volcano.

We will be generating volcano plots using:

1) `ggplot2`: a data visualization package that is offered via the `tidyverse` collection

2) [EnhancedVolcano](https://bioconductor.org/packages/devel/bioc/vignettes/EnhancedVolcano/inst/doc/EnhancedVolcano.html): a package created by Kevin Blighe, Sharmila Rana, and Myles Lewis to generate publication-ready volcano plots.

## Plotting with `ggplot2`

We will begin by using the `ggplot()` function to initialize the basic graph structure. The basic idea is that you can specify different parts of the plot and add them together using the `+` operator. These parts are often referred to as layers.

**As input ggplot() requires a data frame**

Let's start:

```r
#ggplot(resdata) #what happens?
```

Notice, that you will get a blank plot because `ggplot2` requires the user to specify layers using the `+` operator.

One type of layer is called **geometric objects**. Examples include:

* points (`geom_point`, `geom_jitter` for scatter plots, dot plots, etc)
* lines (`geom_line`, for time series, trend lines, etc)
* boxplot (`geom_boxplot`, for boxplots!)

Any plot created with `ggplot()` **must have at least one `geom`**. You can add a `geom` to a plot using the `+` operator

```r
#ggplot(resdata) +
  #geom_point() # note what happens here
```

You will find that even though we have added a layer by specifying `geom_point`, we still get an error. This is because each type of geom usually has a **required set of aesthetics** to be set. Aesthetic mappings are set with the `aes()` function and can be set inside `geom_point()`. If we supplied aesthetics within `ggplot()`, they will be used as defaults for every layer. Examples of aesthetics include:

* position (i.e., on the x and y axes)
* color ("outside" color)
* fill ("inside" color)
* shape (of points)
* line type
* size

**Step 2:** Specify the x- and y-axis, since `geom_point()` requires this information for a scatter plot. In Part I we will use the **raw p-value** (`PValue`) on the y-axis.

```r
ggplot(resdata) +
  geom_point(aes(x = logFC,
                 y = -log10(PValue)))
```

There it is — a volcano! Each dot is one gene.

> **Question:** Where are the genes that are most strongly *induced* by dexamethasone? Where are the genes that did not change at all?

## Classifying genes as up/down/unchanged

**Step 3:** Right now there is no column telling us whether a gene "passes" our cutoffs. We will use two common cutoffs:

+ **Significance:** p-value < 0.05
+ **Effect size:** |log2 fold change| > 1 (i.e., at least a 2-fold change up or down)

First, let's see how many genes pass the p-value cutoff alone:

```r
threshold_pval <- resdata$PValue < 0.05
length(which(threshold_pval)) ## Which values are TRUE, and how many are there?
```

We now have created a logical vector. A `TRUE` value corresponds to genes with a p-value < 0.05 while `FALSE` means it fails this criteria.

Now let's add a column that combines both cutoffs and labels each gene as `Upregulated`, `Downregulated`, or `Unchanged`:

```r
#Start by calling every gene "Unchanged"
resdata$diffexpressed <- "Unchanged"

#if logFC > 1 and PValue < 0.05 set as Upregulated
resdata$diffexpressed[resdata$PValue < 0.05 & resdata$logFC > 1] <- "Upregulated"

#if logFC < -1 and PValue < 0.05 set as Downregulated
resdata$diffexpressed[resdata$PValue < 0.05 & resdata$logFC < -1] <- "Downregulated"

table(resdata$diffexpressed)
```

Now we can color the points using this new column.

```r
ggplot(resdata) +
  geom_point(aes(x = logFC,
                 y = -log10(PValue),
                 colour = diffexpressed))
```

## Polishing the plot

**Step 4:** Let's take a second to change the look of the non-data plotting elements, such as the grid and labels. Many of these elements can be altered within a `theme()` layer.

The ggplot2 `theme` system handles non-data plot elements such as:

+ axis titles and label style
+ plot background
+ presence of major or minor gridlines
+ legend appearance

There are a few built-in themes we can use that will change the background/foreground colors by adding it as an additional layer. Themes can be found [here](https://ggplot2.tidyverse.org/reference/ggtheme.html)

I like the classic theme, so let's add it in.

```r
ggplot(resdata) +
  geom_point(aes(x = logFC,
                 y = -log10(PValue),
                 colour = diffexpressed)) +
  theme_classic()
```

Let's edit the title & x and y labels, including size, text, and position.

```r
ggplot(resdata) +
  geom_point(aes(x = logFC,
                 y = -log10(PValue),
                 colour = diffexpressed)) +
  theme_classic() +
  ggtitle("Dexamethasone vs Untreated (ASM cells)") +
  xlab("Log2 fold change") +
  ylab("-Log10(p-value)") +
  theme(legend.position = "right",
        plot.title = element_text(size = rel(1.25), hjust = 0.5),
        axis.title = element_text(size = rel(1.25)))
```

The default colors don't tell an intuitive story. We can fix this with `scale_color_manual()` — blue for down, grey for unchanged, red for up. Note that ggplot orders the categories alphabetically (Downregulated, Unchanged, Upregulated), so our colors must be listed in that order.

We also add dashed lines with `geom_vline()` and `geom_hline()` to show where our cutoffs are, and use `scale_x_continuous()` to make the x-axis symmetric so the plot is centered on zero.

```r
ggplot(resdata) +
  geom_point(aes(x = logFC,
                 y = -log10(PValue),
                 colour = diffexpressed),
             alpha = 0.6, size = 1.2) +
  geom_vline(xintercept = c(-1, 1), linetype = "dashed", colour = "grey40") +
  geom_hline(yintercept = -log10(0.05), linetype = "dashed", colour = "grey40") +
  theme_classic() +
  ggtitle("Dexamethasone vs Untreated (ASM cells)") +
  xlab("Log2 fold change") +
  ylab("-Log10(p-value)") +
  theme(legend.position = "right",
        plot.title = element_text(size = rel(1.25), hjust = 0.5),
        axis.title = element_text(size = rel(1.25))) +
  scale_color_manual(values = c("blue", "grey70", "red"),
                     name = "") +
  scale_x_continuous(limits = c(-11, 11))
```

Finally, let's write the **number** of up- and down-regulated genes directly on the plot. Instead of typing the numbers by hand, we calculate them so the plot updates automatically if the cutoffs change.


# Part II: Volcano plot w/ EnhancedVolcano

#### Why switch to the adjusted p-value?
A p-value of 0.05 means there is a 5% chance of seeing a result this extreme if the gene is truly unchanged. That's fine for **one** test, but we tested **every gene**:

```r
nrow(resdata) * 0.05   # false positives expected by chance at p < 0.05
```

That is hundreds of genes that could look "significant" purely by chance! To correct for this **multiple testing problem**, `edgeR` calculates an **adjusted p-value** using the Benjamini–Hochberg method, stored in the `FDR` column. Using FDR < 0.05 means that, among the genes we call significant, we expect only about 5% to be false positives.

**From here on we will use the adjusted p-value (`FDR`) instead of `PValue`.**

Let's compare how many genes pass each cutoff:

```r
sum(resdata$PValue < 0.05)   # raw p-value
sum(resdata$FDR < 0.05)      # adjusted p-value
```

And update our up/down classification to use FDR:

```r
resdata$diffexpressed_fdr <- "Unchanged"
resdata$diffexpressed_fdr[resdata$FDR < 0.05 & resdata$logFC > 1]  <- "Upregulated"
resdata$diffexpressed_fdr[resdata$FDR < 0.05 & resdata$logFC < -1] <- "Downregulated"

table(resdata$diffexpressed_fdr)
```

> **Question:** How many genes "disappeared" when we switched from p-value to FDR? Why is it better to lose these genes than to keep them?

## Building the plot
In its most basic usage, `EnhancedVolcano` requires:

+ a data frame (i.e. `resdata`),
+ a column of labels (i.e. `lab = resdata$symbol`),
+ a column name containing log2 fold changes (i.e. `x = 'logFC'`)
+ a column name containing nominal or adjusted p-values (i.e. `y = 'FDR'`)

```r
EnhancedVolcano(resdata,
                lab = resdata$symbol,
                x = 'logFC',
                y = 'FDR')
```

By default `EnhancedVolcano` uses a p-value cutoff of 10e-6 and a fold-change cutoff of 1. Let's set the cutoffs to match ours (FDR < 0.05, |log2FC| > 1), add a title, and change the axis and legend labels so readers know we plotted the **adjusted** p-value.

```r
EnhancedVolcano(resdata,
                lab = resdata$symbol,
                x = 'logFC',
                y = 'FDR',
                ylab = bquote(~-Log[10]~ 'FDR'),
                title = "Dexamethasone vs Untreated",
                subtitle = "Human airway smooth muscle cells",
                FCcutoff = 1,
                pCutoff = 0.05,
                labSize = 4,
                axisLabSize = 12,
                col = c('grey70', 'grey70', 'grey70', 'red3'),
                legendLabels = c('Not sig.', 'Log2FC', 'FDR', 'FDR & Log2FC'),
                legendPosition = 'right',
                legendLabSize = 14,
                legendIconSize = 5.0)
```

There are too many genes labeled here, making the plot look cluttered. Let's label a few select genes.

First, let's get a complete list of our DEGs (using FDR) and save it:

```r
resdata_sig <- resdata %>%
  dplyr::filter(abs(logFC) > 1 & FDR < 0.05) %>%
  dplyr::arrange(FDR)
head(resdata_sig[, c("symbol", "logFC", "PValue", "FDR")], 15)
write.csv(resdata_sig, file = "dex_vs_untrt_DEG.csv", row.names = FALSE)
```

Himes et al. highlight several genes that are well known to respond to glucocorticoids, including **DUSP1, KLF15, PER1, TSC22D3, FKBP5, ZBTB16**, and their headline gene **CRISPLD2**. Let's check them in our results:

```r

resdata %>%
  dplyr::filter(symbol %in% genes_of_interest) %>%
  dplyr::select(symbol, logFC, PValue, FDR, diffexpressed_fdr)
```
