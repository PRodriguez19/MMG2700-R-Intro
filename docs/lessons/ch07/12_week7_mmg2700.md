## Lesson 9: Visualizing the results: Bar Plots (Airway dataset)

# Learning objectives

By the end of this tutorial you should be able to:

1. Identify which columns of a results table and a normalized counts table are needed to make a fold-change bar plot.
2. Convert a **log2 fold change** into a **fold change** and explain what a fold change of 1 means.
3. Subset a large table down to a handful of genes of interest with `dplyr::filter()`.
4. Build a bar plot in `ggplot2` with `geom_col()`, and control the order of the bars.
5. Calculate a fold change for each donor from normalized counts, and summarize it as a mean ± error bar.
6. Polish a bar plot (labels, theme, reference line, significance) and compare it with a published figure.

# Step 0: Setup and about the dataset

## About the dataset

The data come from Himes et al. 2014 (GEO: GSE52778). Researchers wanted to know how **glucocorticoids** — steroid drugs commonly used to treat asthma — change gene expression in **human airway smooth muscle (ASM) cells**.

+ ASM cells from **4 human donors** (`N61311`, `N052611`, `N080611`, `N061011`)
+ Each donor's cells were **untreated (`untrt`)** or treated with **1 µM dexamethasone (`trt`)** for 18 hours
+ **8 samples** in total (4 donors × 2 conditions) — a **paired design**

The five genes in Figure 1B are classic glucocorticoid-responsive genes. If dexamethasone worked, we expect all five to go **up** in treated cells.

We will use two files today:

| File | What it contains | One row = |
|------|------------------|-----------|
| `diffexp_results_edger_airways.txt` | `edgeR` differential expression results (dex vs untreated) | one **gene** |
| `filtlowabund_scaledcounts_airways.txt` | Filtered, normalized counts for every sample | one **gene in one sample** |

## Step 2: From log2 fold change to fold change

`edgeR` reports fold change on a **log2 scale**. Figure 1B shows plain **fold change**. The two are related by:

$$\text{fold change} = 2^{\text{log2FC}}$$

| log2FC | fold change | meaning |
|--------|-------------|---------|
| 0 | 1 | no change |
| 1 | 2 | twice as much in treated cells |
| 3 | 8 | eight times as much |
| −1 | 0.5 | half as much |

**Exercise 2.1 — Calculate by hand.** DUSP1 has a log2FC of about 2.94. Using R as a calculator, what is its fold change?


```{r, ex2-1-solution}
2^2.94
```

DUSP1 is roughly 7.7 times higher in dexamethasone-treated cells.

Now let's add a `fold_change` column for all five genes at once using `mutate()`:

```{r, fold-change}
res_5genes <- res_5genes %>%
  dplyr::mutate(fold_change = 2^logFC)

res_5genes %>% dplyr::select(transcript, logFC, fold_change)
```

## Step 3: Our first bar plot (10 min)

`ggplot2` has two bar geoms:

+ `geom_bar()` **counts** rows for you (the bar height = number of rows in each group).
+ `geom_col()` uses a **value already in your data** as the bar height.

We already have the fold change values, so we use `geom_col()`.

**Exercise 3.1 — Which columns go where?** To make Figure 1B, which column should go on the x-axis and which on the y-axis? Fill in the blanks.

```{r, ex3-1-solution}
ggplot(res_5genes) +
  geom_col(aes(x = transcript, y = fold_change))
```


Notice the bars are in **alphabetical** order, not the order in the figure. `ggplot2` sorts text alphabetically unless we turn the column into a **factor** with the levels in the order we want:

```{r, factor-order}
res_5genes$transcript <- factor(res_5genes$transcript, levels = genes_of_interest)

ggplot(res_5genes) +
  geom_col(aes(x = transcript, y = fold_change))
```

**Exercise 3.2 — Why does the column matter?** 

Change `y = fold_change` to `y = logFC` and re-run the plot. How do the bar heights change? Which version matches Figure 1B?

```{r, ex3-2-solution}
ggplot(res_5genes) +
  geom_col(aes(x = transcript, y = logFC))
```

The **order** of the bars stays the same (bigger log2FC = bigger fold change), but the heights are compressed because log2 squeezes large numbers. For example, KLF15 is ~4.5 on the log2 scale but ~22 on the fold-change scale. Use whichever scale the figure uses.


Finally, a fold change of **1** means "no change". A dashed line at y = 1 helps the reader see that every bar is well above it:

```{r, ref-line}
ggplot(res_5genes) +
  geom_col(aes(x = transcript, y = fold_change), fill = "grey40") +
  geom_hline(yintercept = 1, linetype = "dashed")
```

## Step 4: Fold change for each donor (15 min)

Our bar plot shows one number per gene, but there's no sense of **variability**. We had 4 donors — did every donor respond the same way? To answer this, we go back to the **normalized counts** and calculate a fold change for each donor.

```{r, read-counts}
counts <- read.delim("filtlowabund_scaledcounts_airways.txt", header = TRUE)
head(counts)
dim(counts)
```

This table is in **long format**: each row is one gene in one sample. With ~16,000 genes × 8 samples it has over 127,000 rows!

**Exercise 4.1 — Find the columns.** Using `colnames(counts)` and `head(counts)`, find the column that holds:

| What we need | Column name |
|--------------|-------------|
| Gene symbol | `transcript` |
| Donor (cell line) | `cell` |
| Treatment (trt / untrt) | `dex` |
| **Normalized** counts | `counts_scaled` |

Bonus: there are two count columns, `counts` and `counts_scaled`. Why should we use the scaled one?


`counts` are raw read counts. Samples were sequenced to different depths, so a sample with more reads will have bigger counts for every gene. `counts_scaled` has been normalized (TMM) to correct for this, so samples can be fairly compared.


Keep only our five genes and the columns we need:

```{r, counts-5genes}
counts_5genes <- counts %>%
  dplyr::filter(transcript %in% genes_of_interest) %>%
  dplyr::select(transcript, cell, dex, counts_scaled)

counts_5genes
```

 **Exercise 4.2 — Check your subset.** How many rows should `counts_5genes` have? (Hint: how many genes × how many samples?) Check with `nrow()`.

5 genes × 8 samples = **40 rows**.

```{r, ex4-2-solution}
nrow(counts_5genes)
```


To divide treated by untreated **for each donor**, we need the `trt` and `untrt` values side by side in the same row. `pivot_wider()` spreads the `dex` column out into two new columns:

```{r, pivot}
fc_donor <- counts_5genes %>%
  tidyr::pivot_wider(names_from = dex, values_from = counts_scaled)

fc_donor
```

Now each row is one gene in one donor. Calculate the fold change for each donor:

```{r, fc-donor}
fc_donor <- fc_donor %>%
  dplyr::mutate(fold_change = trt / untrt)

fc_donor
```

> **Question:** Look at KLF15. Do all four donors respond the same amount? Which donor has the largest response?

Now summarize the 4 donors for each gene: the **mean** fold change and the **standard error of the mean (SEM)** = SD / √n.

```{r, summarize}
fc_summary <- fc_donor %>%
  dplyr::group_by(transcript) %>%
  dplyr::summarise(mean_fc = mean(fold_change),
                   sem_fc  = sd(fold_change) / sqrt(n()),
                   n       = n())

fc_summary$transcript <- factor(fc_summary$transcript, 
                                levels = genes_of_interest)
fc_donor$transcript   <- factor(fc_donor$transcript,
                                levels = genes_of_interest)

fc_summary
```

**Exercise 4.3 — Compare the two fold changes.** Compare `mean_fc` in `fc_summary` with `fold_change` from `res_5genes` (the `edgeR` result). Are they the same? Why might they be slightly different?


```{r, ex4-3-solution}
dplyr::left_join(fc_summary,
                 res_5genes %>% dplyr::select(transcript, 
                                              edgeR_fc = fold_change),
                 by = "transcript")
```

They are close but not identical. `mean_fc` is a simple average of four ratios. `edgeR` fits a statistical model to all samples at once (accounting for the donor pairing and the variability of each gene), and its fold change is closer to a geometric mean. A donor with a very large ratio pulls the simple average up more than it pulls the `edgeR` estimate.



Now plot the mean as a bar, add **error bars** with `geom_errorbar()`, and show the individual donors as **points** with `geom_point()`. Notice that each layer uses a **different data frame**:

```{r, bar-errorbar}
ggplot() +
  geom_col(data = fc_summary,
           aes(x = transcript, y = mean_fc),
           fill = "grey40") +
  geom_errorbar(data = fc_summary,
                aes(x = transcript, ymin = mean_fc - sem_fc, ymax = mean_fc + sem_fc),
                width = 0.2) +
  geom_point(data = fc_donor,
             aes(x = transcript, y = fold_change),
             position = position_jitter(width = 0.1, seed = 1)) +
  geom_hline(yintercept = 1, linetype = "dashed")
```

**Exercise 4.4 — Color by donor.** Inside the `aes()` of `geom_point()`, add `colour = cell`. What do you notice about each donor across genes?


```{r, ex4-4-solution}
ggplot() +
  geom_col(data = fc_summary,
           aes(x = transcript, y = mean_fc),
           fill = "grey80") +
  geom_errorbar(data = fc_summary,
                aes(x = transcript, ymin = mean_fc - sem_fc, ymax = mean_fc + sem_fc),
                width = 0.2) +
  geom_point(data = fc_donor,
             aes(x = transcript, y = fold_change, colour = cell),
             size = 2.5,
             position = position_jitter(width = 0.1, seed = 1)) +
  geom_hline(yintercept = 1, linetype = "dashed")
```

Each donor responds in a consistent way across genes. For example, donor N080611 has the smallest fold change for every one of the five genes, and N061011 is often the highest. This donor-to-donor variability is why the paired design matters: comparing each donor's treated cells to its *own* untreated cells removes this baseline difference.

## Step 5: Polish the figure (10 min)

Let's make it publication-ready:

+ `theme_classic()` removes the grey background and grid
+ `labs()` sets the title and axis labels
+ `scale_y_continuous(expand = ...)` makes the bars start right at the x-axis
+ Italicized gene names (convention for gene symbols)

```{r, polish}
p <- ggplot() +
  geom_col(data = fc_summary,
           aes(x = transcript, y = mean_fc),
           fill = "steelblue", width = 0.6) +
  geom_errorbar(data = fc_summary,
                aes(x = transcript, ymin = mean_fc - sem_fc, ymax = mean_fc + sem_fc),
                width = 0.2) +
  geom_point(data = fc_donor,
             aes(x = transcript, y = fold_change),
             size = 1.8,
             position = position_jitter(width = 0.1, seed = 1)) +
  geom_hline(yintercept = 1, linetype = "dashed", colour = "grey40") +
  scale_y_continuous(expand = expansion(mult = c(0, 0.1))) +
  labs(title = "Glucocorticoid-responsive genes in ASM cells",
       x = NULL,
       y = "Fold change (Dex / Untreated)") +
  theme_classic() +
  theme(plot.title = element_text(size = rel(1.2), hjust = 0.5),
        axis.title = element_text(size = rel(1.1)),
        axis.text.x = element_text(size = rel(1.2), face = "italic", colour = "black"))

p
```

### Adding significance

We can label each bar with a significance marker based on the `edgeR` **adjusted p-value** (`FDR`).

**Exercise 5.1 — Which column?** Which column in `res_5genes` should we use to decide whether to add a star? What cutoff will we use?

<details><summary>Show solution</summary>

The `FDR` column (adjusted p-value), with a cutoff of 0.05. We use FDR instead of `PValue` because we tested ~16,000 genes (see the volcano plot tutorial).


```{r, significance}
stars <- res_5genes %>%
  dplyr::mutate(label = dplyr::case_when(FDR < 0.001 ~ "***",
                                         FDR < 0.01  ~ "**",
                                         FDR < 0.05  ~ "*",
                                         TRUE        ~ "ns")) %>%
  dplyr::select(transcript, FDR, label) %>%
  dplyr::left_join(fc_summary, by = "transcript")

# position each star just above the tallest donor point for that gene
max_points <- fc_donor %>%
  dplyr::group_by(transcript) %>%
  dplyr::summarise(ymax = max(fold_change))
stars <- dplyr::left_join(stars, max_points, by = "transcript")

stars

p_final <- p +
  geom_text(data = stars,
            aes(x = transcript, y = ymax * 1.05, label = label),
            size = 6)

p_final
```

Save the figure:

```{r, save}
ggsave("Dex_vs_Untrt_barplot.png", p_final, width = 6, height = 5)
```
