# MMG 2700: Foundations in R for Life Sciences

## Introduction 

This course introduces students to programming in R with a focus on applications in microbial and cancer genomics. Through a combination of lectures, hands-on programming activities, and collaborative discussions, students will develop foundational computational skills for working with and interpreting biological datasets. Topics will include R syntax and programming fundamentals, data wrangling and manipulation with the `tidyverse`, exploratory data analysis and statistics, and data visualization using `ggplot2`. Students will also learn principles of reproducible research and effective communication of biological data through code, figures, and written interpretation. 

In the second half of the course, students will apply these skills to discipline-specific genomics applications, including microbiome composition analysis and the exploration of transcriptional and mutational profiles in cancer datasets. Students will critically evaluate primary research literature and use real-world biological datasets to practice computational approaches commonly used in modern genomics research. By the end of the course, students will be equipped with practical R programming and data analysis skills that support reproducible research in microbial genomics, cancer biology, and related areas of the life sciences.

## Required software: 
This course will be taught using R and RStudio. To install R locally, please see installation instructions below. A mental model that will aid in understanding the steps below; R = the engine, RStudio = the interface. 

??? info "R Installation Instructions for macOS"

    + Download R from the [CRAN](https://cran.r-project.org/bin/macosx/) website.
    + Select the .pkg file for the latest R version
    + Double click on the downloaded file to install R
    + Go to the RStudio IDE download page (https://docs.posit.co/ide/user/#rstudio-ide-oss-downloads)
    + Under All Installers select RStudio xxxx.yy.zz-uuu.dmg - macOS 10.13+ (where x, y, z, and u represent version numbers)
    + Double click the file to install RStudio

??? info "R Installation Instructions for Windows"

    + Download R from the [CRAN](https://cran.r-project.org/bin/windows/base/) website.
    + Run the .exe file that was just downloaded
    + Go to the RStudio IDE download page (https://docs.posit.co/ide/user/#rstudio-ide-oss-downloads)
    + Under All Installers select RStudio xxxx.yy.zz-uuu.exe - Windows (where x, y, z, and u represent version numbers)
    + Double click the file to install it
